# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately, through either channel:

- GitHub private vulnerability reporting: the **Security** tab of this repository, then **Report a vulnerability**.
- Email: security@revition.com.

Include the CLI version (`revition --version`), your OS, the steps to reproduce, and the impact you observed. Remove
tokens, session credentials and personal data from anything you send.

## What to expect

| Step | Target |
|---|---|
| Acknowledgement of your report | within 2 business days |
| Fix for a critical vulnerability | within 7 days of confirmation |
| Fix for other severities | in a scheduled release, with the timeline shared in the advisory |

We coordinate disclosure with you, publish a GitHub security advisory for every fixed vulnerability, and credit you
unless you ask us not to.

## Supported versions

| Version | Supported |
|---|---|
| Latest minor release | Yes |
| Older releases | No; please upgrade |

There is no pre-1.0 release yet. This table is updated with each release.

## Bug bounty

There is no bug bounty programme at this time.
